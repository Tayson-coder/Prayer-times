# هوية التصميم

صفحة القراءة على طراز المصحف والكتب القديمة، كما طلب صاحب التطبيق: رق دافئ، نقش هندسي خفيف،
خط نسخ عريض بتشكيل كامل، وذكر واحد في كل صفحة.

## الألوان

| الاسم | فاتح | داكن |
|---|---|---|
| parchment_top / bottom | `#F8EFDD` / `#EEDDBC` | `#231A12` / `#17110B` |
| ink (النص) | `#2E1C0F` | `#F1E4CC` |
| muted | `#7A6048` | `#BFA584` |
| accent (رقم الذكر، عدد المرات، المسبحة) | `#B4692A` | `#E3A35E` |
| control (حدود الأزرار) | `#4A2F1B` | `#D9C2A0` |
| card / card_stroke | `#FBF5E9` / `#D9BF94` | `#2A2017` / `#5B4630` |

النقش: نجمة ثمانية (مربعان متداخلان) مع خطوط وصل ودوائر في الزوايا، بلون `pattern` وشفافية خفيفة (`ParchmentDrawable`).

## الخطوط

- **Amiri Bold:** نص الذكر (٢٩sp افتراضياً، قابل للتغيير)، عدد المرات، العناوين.
- **IBM Plex Sans Arabic:** الواجهة والأرقام الصغيرة.

## صفحة القراءة

```
 ↪   ──◆· أذكار الصباح ·◆──   ⓘ
            ( 2 / 26 )
        نص الذكر بالتشكيل
          ثَلَاثُ مَرَّاتٍ
 ⟲   ‹    ( مسبحة: العدد )   ›   ⇪
```

- الشريط السفلي من اليمين: مشاركة، السابق، المسبحة، التالي، إعادة عدّ الذكر.
- المسبحة (`TasbihView`): ١٨ حبة، وحبة مميزة بشرّابة تتقدم مع كل ضغطة، والعدد المتبقي في المنتصف،
  وعلامة صح عند الإتمام ثم الانتقال للذكر التالي.
- الضغط على النص يعدّ أيضاً.
