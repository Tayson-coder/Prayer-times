# ملفات الأذان

ضع هنا ملفات الأذان بصيغة MP3، واجعل اسم كل ملف مطابقاً لمعرّف المؤذن:

| الملف | المؤذن |
|---|---|
| `abdulbasit.mp3` | الشيخ عبد الباسط عبد الصمد |
| `refaat.mp3` | الشيخ محمد رفعت |
| `tobar.mp3` | الشيخ نصر الدين طوبار |
| `minshawi.mp3` | الشيخ محمد صديق المنشاوي |
| `husary.mp3` | الشيخ محمود خليل الحصري |
| `banna.mp3` | الشيخ محمود علي البنا |
| `naina.mp3` | الشيخ أحمد نعينع |
| `mulla.mp3` | الشيخ علي أحمد ملا (الحرم المكي) |
| `hadrawi.mp3` | الشيخ فاروق حضراوي (الحرم المكي) |
| `bukhari.mp3` | الشيخ عصام بخاري (المسجد النبوي) |
| `abdulmajeed.mp3` | الشيخ عبد المجيد السريحي (المسجد النبوي) |
| `afasy.mp3` | الشيخ مشاري راشد العفاسي |
| `qatami.mp3` | الشيخ ناصر القطامي |
| `aqsa.mp3` | أذان المسجد الأقصى |

لإضافة مؤذن جديد: أضف سطراً في `js/muezzins.js` وضع ملفه هنا بنفس المعرّف.

يمكن أيضاً بدلاً من ذلك رفع الملف من داخل التطبيق (الإعدادات ← أصوات المؤذنين)
أو لصق رابط مباشر لملف صوتي.

> استخدم تسجيلات مسموح لك باستخدامها، خصوصاً إذا كنت ستنشر التطبيق للعامة.
