# مواقيت الصلاة 🕌

تطبيق ويب (PWA) لمواقيت الصلاة مع الأذان بأصوات أشهر المؤذنين. واجهته عربية بالكامل.

## المميزات

- **حساب فلكي دقيق بدون إنترنت**: يحسب المواقيت على الجهاز مباشرة، بلا أي خدمة خارجية.
- **14 طريقة حساب**: الهيئة المصرية، أم القرى، رابطة العالم الإسلامي، الخليج، الإمارات، الكويت، قطر، الأردن، الجزائر، المغرب، تونس، تركيا، كراتشي، ISNA.
- **العصر**: على مذهب الجمهور أو المذهب الحنفي.
- **الموقع**: تحديد تلقائي (GPS)، أو اختيار من قائمة نحو 30 مدينة، أو إدخال الإحداثيات يدوياً.
- **التاريخ الهجري** (أم القرى) والميلادي، وعدّاد تنازلي للصلاة القادمة.
- **الأذان التلقائي** عند دخول الوقت، مع إمكانية إيقافه لكل صلاة على حدة.
- **قائمة بأشهر المؤذنين**: عبد الباسط عبد الصمد، محمد رفعت، نصر الدين طوبار، المنشاوي، الحصري، البنا، نعينع، علي أحمد ملا، فاروق حضراوي، عصام بخاري، عبد المجيد السريحي، العفاسي، ناصر القطامي، أذان المسجد الأقصى.
- **مؤذن خاص لصلاة الفجر** (لأذان فيه «الصلاة خير من النوم»).
- **تعديل يدوي بالدقائق** لكل صلاة لمطابقة مسجدك.
- **إشعارات** على الجهاز، ووضع ليلي تلقائي، ويعمل بدون إنترنت بعد أول فتح، ويمكن تثبيته على الشاشة الرئيسية.

## أصوات الأذان

التسجيلات الصوتية **غير مرفقة** في المستودع (لها حقوق نشر). لكل مؤذن ثلاث طرق لإضافة صوته:

1. **من داخل التطبيق**: الإعدادات ← أصوات المؤذنين ← «رفع ملف». يُحفظ الملف على جهازك فقط.
2. **رابط مباشر** لملف MP3 في نفس المكان.
3. **ملف في المجلد** `audio/` باسم المؤذن، مثل `audio/abdulbasit.mp3` (انظر `audio/README.md`).

إذا لم يوجد ملف للمؤذن المختار، يُشغَّل تنبيه صوتي بديل حتى لا يفوتك الوقت.

## التشغيل

لا يحتاج أي تثبيت أو بناء. شغّل أي خادم ملفات بسيط داخل المجلد:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

أو انشره مجاناً على GitHub Pages.

> **ملاحظة**: المتصفحات تمنع تشغيل الصوت تلقائياً قبل أن يتفاعل المستخدم، لذا اضغط زر
> «تفعيل الأذان التلقائي» مرة واحدة بعد فتح الصفحة، واترك الصفحة مفتوحة (ولو في الخلفية).
